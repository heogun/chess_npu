# Legacy Implementation Archive

These directories are frozen references and are not part of the canonical build:

- `rtl_m4_bram`: simulation-oriented BRAM implementation
- `fpga_top_soc_ddr`: failed DDR-streaming Platform Designer component
- `arm_m4`: matching HPS software, probes, and generated binaries

The archive is retained to reproduce prior results and compare G2 vectors. Do
not edit files here while implementing the canonical design.
