# M4 전체 refresh RTL 보고서

수행일: 2026-11-05. **이 결과는 Verilator 시뮬레이션이다. 보드 정확성이나 부팅을 입증하지 않는다.** 메모리는 C++ 모델이며 실제 F2SDRAM이 아니다.

아래 수치는 ABI 2 코어를 전체 refresh 모드로 다시 실행한 결과다. 증분 경로는 [M5 보고서](M5_incremental.md)에 있다.

## 결과: 시뮬레이션 게이트 통과 (아래 공백 제외)

| 항목 | 결과 |
|---|---|
| 평가 상태 | 100,000 (M2와 같은 seed `20261105` corpus) |
| 모든 tensor를 비교한 상태 | 100,000 |
| 비교한 값 | 328,742,679 |
| 불일치 / 최대 오차 | 0 / 0 |
| 오류 / fallback | 0 / 0 (코어에 fallback 경로 없음) |
| 산술 단위시험 | 39,131,175건, 불일치 0 |
| 음성·시스템 시험 | 59건 모두 통과 |

비교 대상은 누산기(양 관점 2,048개), PSQT 16개, FT 1,024개, FC0 32개, concat 128개, FC1 32개, FC2, fwd, skip, 나눗셈 전 값과 최종 pair다. 모두 CSR을 통해 읽어 공식 스칼라 빌드의 값과 비교했다.

| Coverage | 값 |
|---|---|
| bucket 0~7 | 61,776 / 19,379 / 6,695 / 3,234 / 2,686 / 2,216 / 2,050 / 1,964 |
| 차례 (백 / 흑) | 50,140 / 49,860 |
| 메모리 프로파일 | 4종 각 25,000 상태. 대기 0~75%, 응답 정지 0~60%, 지연 1~120 cycle |
| 시뮬레이션 cycle | 3,828,226,943 |

음성·시스템 시험은 다음을 포함한다.

- 식별자 CSR, 잘못된 magic, ABI, hash, net ID, 예약 비트, 특징 수, 특징 범위, 정렬의 거부
- IRQ 동작과 busy 중 재시작 무시
- 실행 중 소프트 리셋 8개 시점과 중단 시점 sweep
- 슬롯 유효성, 소유자, 무효화 경로
- 메모리 무응답 시 watchdog, 그 뒤 응답 폐기와 정상 복귀
- 실행 중 하드웨어 리셋

산술 단위시험은 16-bit clamp와 8×8 곱을 전수 검사하고, 32·64-bit 영역은 조밀한 구간, 경계, 무작위 값을 사용한다. 공식 스칼라 식을 옮겨 쓴 비교이며 전체 비교의 기준은 공식 코드다.

```bash
tools/run-m4.sh 100000 20261105
```

첫 실행에서 FC 편향을 33워드가 아닌 17워드만 읽는 RTL 버그가 FC1 불일치로 드러나 수정했다.

## 남은 공백

- **active 특징이 많은 경우:** corpus 최대는 81개이고 슬롯은 256개다. 82~256개 구간은 공식 golden과 비교하지 않았다.
- **Corpus 치우침:** 62%가 bucket 0이다.
- **게이트 수준:** post-fit 시뮬레이션, 실제 DDR, CDC, 온보드 실행은 수행하지 않았다.
